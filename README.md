# Заметь наш стиль

Публичное демо студии: четыре направления с официального сайта и проверенные открытые анонсы. На главном экране есть Starters, Kids, Юниоры, Mama Dance, фильтр направлений, ЗАНАС Dance Battle 28 ноября 2026 и KAMON «Sorry» 4–10 января 2027. Расписание — публичный снимок, сверенный 24 ноября 2026; не вымышленный календарь занятий. У каждого мероприятия есть ссылка на первоисточник.

Тестовые карточки, журнал, действия управления и «Мой тайминг» остаются на вымышленных данных и явно отделены от анонсов. Переключатель ролей — демонстрация, а не авторизация. Не вводите реальные имена, контакты, посещаемость или оплату.

Обновление публичных карточек не меняет идентификаторы тестовых занятий, формат/ключ локального журнала, PWA id, scope или start_url. Сохранённые отметки и история остаются на том же устройстве и в том же браузере. Изменения расписания и событий, интерес и прочтение работают только в сеансе; общей базы, рабочей регистрации, платежей и межустройственной синхронизации пока нет.

Иконка v2 — адаптация фирменного знака без букв и надписей, подготовленная imagegen по официальному логотипу и проверенная визуально. Файлы PNG 180, 192 и 512 пикселей имеют новые имена, чтобы не переиспользовать старое изображение из кэша. iOS может сохранить прежнюю иконку у уже добавленного ярлыка; автоматическая смена на физическом iPhone не проверена. Не очищайте данные сайта ради иконки: это удалит локальный журнал.

## Проверки

`node tests/verify-public.cjs` проверяет синтаксис, публичный набор, размеры иконок, состав нового офлайн-кэша, неизменность PWA identity, загрузку вымышленного журнала старой версии и следующую запись без его сброса. Сценарии браузера и физического iPhone проверяются отдельно.

## Публикация на GitHub Pages

1. Создайте отдельный репозиторий для демо; не заменяйте действующий сайт студии. Распакуйте этот архив; загрузите файлы в корень ветки `main`, включая папку `icons` и файл `.nojekyll`. Не загружайте ZIP вместо его содержимого.
2. В репозитории откройте Settings → Pages. Выберите Deploy from a branch → main → / (root). Сохраните; дождитесь успешной сборки в Actions.
3. Откройте HTTPS-адрес, указанный в Settings → Pages. Проверьте «Мой тайминг» → «Альфа»: сбор 12:20, начало блока 13:15, седьмой выход; кнопка переключает неизвестное время выхода на 14:35 и обратно. Первый визит нужен онлайн.
4. На iPhone откройте ссылку в Safari. Нажмите «Поделиться» → «На экран Домой», включите «Открывать как веб‑приложение», если этот переключатель есть, затем нажмите «Добавить». Откройте иконку Заметь наш стиль с экрана «Домой». Это веб‑приложение, не App Store.

Офлайн-кэш содержит только файлы приложения. Переключения времени на сцене ознакомительные; отметки деможурнала локальны на устройстве и не синхронизируются. При обновлении файлов обновите версию в `sw.js`, чтобы новая версия заменила кэш.
